# Mina Park — Portfolio

A single-page portfolio built with HTML, CSS, and JavaScript. It includes an about section, filterable projects, skills, a contact form, and a light/dark theme.

## View it

Open `index.html` in a browser.

## Files

- `index.html` — page structure and content
- `style.css` — layout and colors
- `main.js` — menu, project filters, theme, and form checks

Edit the text in `index.html` to replace the sample name, projects, and contact details. The contact form stays in the browser and does not send email.
